# 🩺 Breast Cancer Recurrence Prediction Using Decision Tree

## 📌 Project Overview

BreastCare AI is a machine learning-based web application developed to predict breast cancer recurrence events using a Decision Tree Classification model.

The system accepts patient-related clinical features through a web interface and predicts whether the case belongs to:

- `recurrence-events`
- `false-recurrence-events`

The project combines Machine Learning, Python, Flask, HTML, and CSS to provide an interactive prediction system.

> ⚠️ **Medical Disclaimer:** This project is developed for academic and educational purposes only. It is not a medical diagnostic system and should not be used for clinical decisions, treatment, or patient care.

---

## 🎯 Objectives

- Develop a machine learning model for breast cancer recurrence classification.
- Apply data preprocessing and feature encoding techniques.
- Train a Decision Tree Classifier.
- Evaluate the model using accuracy, precision, recall, F1-score, and confusion matrix.
- Develop a Flask-based web application.
- Provide an easy-to-use interface for entering patient information.
- Display the predicted class and model probability.
